SMART BUCKETS (Core Concept)
--------------------------------------------------------------------------------
  1. Operations       — Daily running costs, supplier payments, inventory
  2. Obligations      — Rent, salaries, utilities, loan repayments
  3. Profit Reserve   — Emergency buffer, growth capital, stability fund
  4. Owner Salary     — Structured personal compensation from business
  5. Growth           — Marketing, equipment, expansion investments

  IMPORTANT: Buckets use dynamic AI allocation, NOT fixed ratios.
  Allocation adapts based on:
    - Business type (retail, restaurant, services, wholesale, online, freelancer)
    - Upcoming obligations and their urgency
    - Reserve coverage ratio
    - Revenue trend (growing / stable / declining)
    - Owner withdrawal behavior

SMART BUCKET ALLOCATION LOGIC
--------------------------------------------------------------------------------

  BUSINESS TYPE PROFILES (base allocation %)
  ┌─────────────┬────────────┬─────────────┬─────────┬────────────┬────────┐
  │ Type        │ Operations │ Obligations │ Reserve │ Own Salary │ Growth │
  ├─────────────┼────────────┼─────────────┼─────────┼────────────┼────────┤
  │ Retail      │    50%     │    25%      │   12%   │    10%     │   3%   │
  │ Restaurant  │    55%     │    22%      │   10%   │    10%     │   3%   │
  │ Services    │    40%     │    28%      │   15%   │    12%     │   5%   │
  │ Wholesale   │    60%     │    20%      │   10%   │     8%     │   2%   │
  │ Online      │    45%     │    22%      │   15%   │    12%     │   6%   │
  │ Freelancer  │    30%     │    30%      │   20%   │    15%     │   5%   │
  └─────────────┴────────────┴─────────────┴─────────┴────────────┴────────┘

  DYNAMIC ADJUSTMENTS:
  - Low obligation coverage  → +10% obligations, -7% operations
  - Declining revenue trend  → +5% reserve, -3% growth
  - Growing revenue (safe)   → +2% growth, +1% owner salary

  AI ALWAYS RECOMMENDS FIRST — never auto-forces allocation.
  User sees: [Accept] [Adjust] on every recommendation.

SUPABASE DATABASE SCHEMA
--------------------------------------------------------------------------------
  Tables:
    businesses         — owner_id, name, type, salary_goal
    buckets            — balance, target_pct, name, color
    transactions       — amount, type, category, description, date, bucket
    obligations        — name, amount, due_date, priority, status, recurring
    allocations        — total_amount, splits (jsonb), accepted_at
    insights           — message, detail, severity, category, action
    scores             — overall, payment_timeliness, reserve_consistency,
                          salary_stability, personal_leakage, loan_readiness
    owner_withdrawals  — amount, date, note

  All tables have Row Level Security (RLS) enabled.
  Users can only access data tied to their own business.

--------------------------------------------------------------------------------
FINANCIAL DISCIPLINE SCORE (0–100)
--------------------------------------------------------------------------------
  Component breakdown:
    Payment Timeliness    — 30 pts max (on-time obligations)
    Reserve Consistency   — 25 pts max (steady reserve growth)
    Salary Stability      — 20 pts max (owner salary within limit)
    Penalty Deductions    — 20 pts max (late payments reduce this)
    Base                  —  5 pts

  Score Labels:
    80–100 → Excellent (green)
    60–79  → Good (burnt-peach)
    40–59  → Fair (warning)
    0–39   → At Risk (red)

  Loan Readiness: Derived from overall score.
  Score 80+ → unlocks preferential banking rates.
